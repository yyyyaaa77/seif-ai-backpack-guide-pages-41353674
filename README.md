# 赛夫 AI 背包导购小程序 Web 版

这是一个可直接在浏览器运行的移动端小程序原型，采用赛夫集团品牌红与简洁商品陈列。商品池现包含 28 个已核验 SKU，覆盖母婴、校园、通勤、时尚穿搭和轻户外。

## 运行

直接双击 `index.html` 即可。

也可以在当前目录启动静态服务器：

```powershell
python -m http.server 8080
```

然后访问 `http://localhost:8080`。

## 快速演示

- `index.html?demo=result`：直接进入“通勤 + 600 元内 + 商务简约”的推荐结果。
- `index.html?demo=operator`：直接打开运营驾驶舱并生成首版优化方案。
- `index.html?demo=catalog`：直接打开扩充后的 28 款商品库。

## 已实现

- 对话式需求抽取：使用场景、预算、受众、风格、禁忌项；覆盖通勤、校园、带娃、穿搭、旅行和户外。
- 轻量 Planner：根据缺失信息连续追问，最多 3 个关键问题。
- 硬条件过滤：预算、电脑尺寸和明确禁忌项不会被模型解释绕过。
- 多目标排序：场景匹配、受众、风格、预算 gap、商品能力和风险惩罚。
- 真实 SKU 卡片：官方商品照片、规格、库存快照与来源链接。
- 场景与风格筛选：商品库支持品类筛选和商务、简约、韩系、复古、精致时尚、清新可爱、功能型、户外运动等风格筛选。
- 可解释推荐：匹配依据、场景/用途/风格/人群标签、主要取舍和“为什么没有推荐”。
- 商品详情与参数对比。
- 运营驾驶舱：需求信号、经营洞察、策略生成与 Markdown 导出。
- 成交链路演示：商品承接页、缺货替代与到货提醒。

## 数据说明

商品库包含 28 个可追溯 SKU，商品结构为：妈咪包 6 款、学生书包 6 款、通勤包 6 款、时尚背包 6 款、轻户外包 4 款，其中 12 款位于 50–100 元价格带。

- 小米商城：3 款通勤包，直接读取官方价格、库存状态和商品图。
- 苏宁易购：24 款商品，覆盖妈咪包、学生书包、通勤包、韩系/复古时尚包和轻户外包，记录商品 ID、标题、型号、现价、售卖状态和商品图。
- 品牌官网：Thule Paramount Daypack Lite 20L，保留官网直链、型号、规格、价格与库存状态。

所有价格、库存状态和商品图均在 2026-11-24 从对应商品页核验。商品图已保存到本地 `assets/products/verified/`，商品详情中同时提供原图链接和商品来源链接。库存仅代表页面显示状态，不是实时库存数量；实际价格、库存与配送以购买渠道页面为准。

商品详情中的“官方商品快照”或“电商商品快照”用于说明事实来源，不是评论洞察。正式接入赛夫 AI 商业智能引擎时，真实库存应由渠道接口同步，评论洞察应带样本量、时间范围、来源和置信度。

## 正式接入

当前对话与排序均由本地规则引擎模拟。线上版本建议将以下环节服务化：

1. 需求抽取与 Planner：调用大模型并按字段白名单校验。
2. 商品事实：接入赛夫商品中心、实时价格与库存。
3. 推荐排序：先规则门控，再调用排序模型。
4. 解释生成：只使用排序追踪与知识库证据。
5. 成交链路：替换为真实商品承接页与订单接口。
